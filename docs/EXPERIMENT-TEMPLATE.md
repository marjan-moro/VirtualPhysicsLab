# Experiment authoring template

Copy the headings and prompts below into an experiment draft. Replace each prompt with sourced content, and omit optional sections that have no applicable material.

## Catalog record

- ID and stable URL slug
- Title, subtitle, and short description
- Start year, optional end year, and precision or display label
- Scientist or collaboration names
- Historical era, scientific categories, difficulty, and milestone kind
- Search keywords, related experiment IDs, and references
- Image path, text alternative, credit, and license if applicable
- Publication status and laboratory module key, based on the work completed

## Explore

- State the central scientific question.
- Describe what was known before the milestone, how the original apparatus or observation addressed the question, and what the sources support about its historical significance.
- Identify documented outcomes, uncertainties, or later interpretations.
- Give a conceptual question or a modern application.

## Understand

- Define the governing relationship, variables, signs, and units.
- Derive any equation a student will use in the lab.
- Explain the measurement procedure, what is being measured, and known sources of error.
- Work through a quantitative example and link to relevant sources.

## Simulate

- State the coordinate system, parameters, defaults, physical assumptions, and limits.
- Define the state and solver, including initial or boundary conditions where applicable.
- Describe plot axes, trial data fields, and the expected outcomes under a known setup.
- Design challenges with testable conditions or clearly described answers.
- Specify analytical references or numerical convergence and conservation checks.

## Before publishing

- Validate the catalog entry, content module, and lab loader.
- Confirm that each control applies to the modeled system and that reset restores defaults.
- Run the test suite and static build. Check the chapter, responsive layout, keyboard controls, and laboratory outputs.
- Document the choices that limit the model and the features still planned.
